# MP4ファイル分割処理

**実行手順書（PowerShell）**

---

## 1. 目的

指定フォルダ直下に存在する mp4 ファイルを、
**10ファイル単位で連番フォルダに自動分類する**。

* フォルダ名形式：`YYYYMMNN`（例：`20251001`）
* 実行前検証（dry-run）あり
* 実行ログを自動出力
* 例外発生時は自動ロールバック

---

## 2. 事前条件

### 2.1 必要環境

* Windows 10 / 11
* PowerShell 5.1 以上
* 管理者権限：不要

### 2.2 対象ファイル条件

* 拡張子：`.mp4`
* 対象ファイルは **スクリプトと同じフォルダ直下** に配置すること
* サブフォルダ内の mp4 は対象外

---

## 3. 配置構成

```
作業フォルダ
├─ split_mp4_production.ps1
├─ movie01.mp4
├─ movie02.mp4
├─ movie03.mp4
└─ ...
```

---

## 4. 初回実行時の注意（必須）

PowerShell の実行ポリシーにより、スクリプト実行がブロックされる場合がある。

### 実行ポリシー確認

```powershell
Get-ExecutionPolicy
```

### `Restricted` の場合（初回のみ）

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

※ 管理者権限不要
※ 以後の実行に影響なし

---

## 5. 実行手順

### 5.1 PowerShell 起動

1. 対象フォルダで **Shift + 右クリック**
2. 「PowerShell ウィンドウをここで開く」を選択

---

### 5.2 事前確認（dry-run 実行）

**必ず最初に実行すること**

```powershell
.\split_mp4_production.ps1 -DryRun
```

#### dry-run 実行時の挙動

* ファイル移動：**行われない**
* フォルダ作成：**行われない**
* ログ出力：**行われる**
* 移動予定内容をコンソールとログで確認可能

---

### 5.3 本番実行（実移動あり）

dry-run 結果に問題がなければ実行。

```powershell
.\split_mp4_production.ps1
```

#### 本番実行時の挙動

* mp4 ファイルが実際に移動される
* フォルダが自動生成される
* 例外発生時は自動ロールバック
* 全処理内容がログに記録される

---

## 6. 処理結果

### 6.1 フォルダ構成例

```
作業フォルダ
├─ 20251001
│   ├─ movie01.mp4
│   ├─ movie02.mp4
│   └─ movie10.mp4
├─ 20251002
│   ├─ movie11.mp4
│   └─ movie20.mp4
├─ 20251003
│   └─ movie21.mp4
└─ _log
    └─ split_mp4_YYYYMMDD_HHMMSS.log
```

---

## 7. ログについて

### 7.1 ログ保存先

```
作業フォルダ\_log\
```

### 7.2 ログ内容

* 実行開始時刻
* dry-run / 本番の別
* 作成フォルダ名
* 各ファイルの移動履歴
* 例外発生時のロールバック履歴

---

## 8. 異常時の挙動

### 8.1 途中でエラーが発生した場合

* 移動済みファイルは **すべて元の場所へ戻される**
* ログに `ROLLBACK` 記録が残る
* 手動復旧作業は不要

---

## 9. 再実行について

* dry-run / 本番ともに **何度でも再実行可能**
* 移動先に同名ファイルが存在する場合は処理を中断し、上書きは行わない（`-LiteralPath` 版スクリプトでの動作）

---

## 10. 補足

* フォルダ名の年月（`202510`）を変更したい場合は
  `split_mp4_production.ps1` 内の `$BaseName` を編集すること
