# Split_mp4.ps1 — 実行手順書

## 概要

`src/scripts/Split_mp4.ps1` は、スクリプトと同じフォルダ直下にある `.mp4` ファイルを
**10ファイル単位で連番フォルダへ自動分類する** PowerShell バッチである。

| 項目 | 内容 |
|------|------|
| 対象拡張子 | `.mp4`（直下のみ。サブフォルダは対象外） |
| 分割単位 | 10ファイル（`$Config.GroupSize` で変更可） |
| フォルダ命名 | `<BaseName><連番2桁>`（例：`20251001`） |
| 並び順 | ファイル名昇順 |
| ログ出力先 | `_log/split_mp4_YYYYMMDD_HHMMSS.log`（UTF-8） |
| 必要環境 | Windows 10/11、PowerShell 5.1 以上、管理者権限不要 |

## 設定変更

スクリプト冒頭の `$Config` ブロックで変更する。

```powershell
$Config = [PSCustomObject]@{
    BaseName  = "202510"   # フォルダ名プレフィックス（年月など）
    GroupSize = 10         # 1フォルダあたりの最大ファイル数
    RootDir   = $PSScriptRoot
    LogDir    = Join-Path $PSScriptRoot "_log"
}
```

`BaseName = "202601"` にすると `20260101`, `20260102`, ... という名前でフォルダが作られる。

## 実行手順

### 配置

`Split_mp4.ps1` を整理したい `.mp4` ファイルと**同じフォルダ**に置く。

```
作業フォルダ/
├── Split_mp4.ps1
├── movie01.mp4
├── movie02.mp4
└── ...
```

### ① DryRun（必須・事前確認）

**本番実行前に必ずこちらを先に実行すること。**

```powershell
.\Split_mp4.ps1 -DryRun
```

- ファイル移動・フォルダ作成は**一切行わない**
- フォルダ作成予定は `MKDIR:` としてログに出力される（`[DRY-RUN]` プレフィックスは付かない）
- ファイル移動予定は `[DRY-RUN] MOVE:` としてログに出力される
- 移動予定内容をコンソールとログで確認できる

### ② 本番実行

DryRun 結果に問題がなければ実行する。

```powershell
.\Split_mp4.ps1
```

## ログの内容

時刻付きで以下を記録する。

| ログ識別子 | 意味 |
|-----------|------|
| `開始:` | 処理開始・対象ファイル数・DryRun 状態 |
| `MKDIR:` | フォルダ作成 |
| `[DRY-RUN] MOVE:` | DryRun 時の移動予定 |
| `MOVE:` | ファイル移動（本番） |
| `ERROR:` | 異常検知（処理中断） |
| `ROLLBACK:` | ファイルを元の場所へ復元 |
| `RMDIR:` | 空フォルダを削除 |
| `正常終了` | 全処理が正常に完了 |
| `処理終了` | finally ブロック終了 |

## 異常時の挙動（ロールバック）

処理途中で例外が発生した場合、`finally` ブロックで自動的にロールバックを試行する。

- 移動済みファイルを**移動と逆順**で元の場所へ戻す
- ロールバック後、スクリプトが作成した空フォルダを削除する
- 復元先に同名ファイルが既に存在する場合は上書きせず、スキップしてログに記録する
- ロールバック個別アイテムの失敗は後続の復元を止めない（失敗分はログに記録）

### ロールバックの保証範囲

ロールバックは `finally` ブロックで実行されるため、**Ctrl+C による中断でも試行される**。

ただし以下の状況では `finally` が実行されずロールバックは保証されない。

- プロセスの強制終了（`taskkill /F` 、タスクマネージャーの「タスクの終了」等）
- OS クラッシュ・電源断

**重要なファイルは事前にバックアップを取ること。**

---

## 安全設計

- すべてのファイル・フォルダ操作に `-LiteralPath` を使用（`[` `]` `*` `?` を含むファイル名も安全）
- 移動先に同名ファイルが存在する場合は即座に中断（上書きなし）
- `Move-Item -Force` は使用しない
- `Set-StrictMode -Version Latest` と `$ErrorActionPreference = "Stop"` で予期しない動作を防止
- 正常完了フラグ（`$script:正常完了`）により Ctrl+C 割り込み時も finally でロールバックを試行

## テストの実行方法

### 正常系テスト

```powershell
.\test_split_mp4.ps1
```

ダミー mp4 を自動生成し、DryRun → 本番実行を段階的に確認する。テスト後にクリーンアップ。

### 異常系テスト

```powershell
.\test_split_mp4_abnormal.ps1
```

以下の3シナリオを検証する。

| シナリオ | 期待結果 |
|---------|---------|
| 移動先に同名ファイルが存在する | 即中断・移動ゼロ |
| 処理途中でファイルが消える | 例外発生・全ロールバック実行 |
| 読み取り専用ファイルが含まれる | 例外発生・ロールバック実行 |

### ステップ実行テスト

```powershell
.\test_split_mp4_step.ps1
```

1ファイルずつ Enter で進める対話式ウォークスルー。`Split_mp4.ps1` を呼び出すのではなく、同等の分割ロジックを内包しており、各ステップでフォルダ作成・ファイル移動の様子を目視確認できる。ロジックの動作理解や手動検証に使用する。

## 注意事項

- `.mp4` 以外の拡張子は対象外
- サブフォルダ内のファイルは対象外
- 並列処理は未実装（安全性優先）
- ロールバックは例外発生時のみ自動実行。正常終了後の取り消しは手動対応
- `src/archive/` 内の旧バージョンは参照用。実運用では使用しないこと
